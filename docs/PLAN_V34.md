# PLAN_V34「通脉」

> 主题释义：打通堵塞的经脉——节奏曲线的淤塞（r8~r9 占全程一半的 dead time）、世界大事整根支柱的沉睡、
> 悟道环路对成长曲线的旁路、经济端两处正期望套利、战斗规则的五处半吊子接线，一并疏通。
> 六路深审（战斗/经济/修炼节奏/世界/UX/工程）+ 主线复核后定稿；**不新增大块内容，以疏通与仪式感为主**。

## 审计结论摘要（定性）

1. **节奏**：实算全程纯修炼 ≈2850 日，闭关 1.6× 后实玩 ≈5~6 年/周目——而 v30 校准目标 12~20 年、
   世界大事首现钉在 10~14 年 ⇒ **世界大事系统对正常玩家整周目零触发**（"世界活性"支柱事实死亡）；
   r8+r9 两个境界占纯修炼时长 49%，期间无任何新机制。
2. **悟道环路**：听讲(300贡献→+8感悟) → 悟道(20感悟→1600×eco 修为) 折算汇率 80×eco/点，
   相当于单日悟道 ≈ 219 倍单日修炼产出；靠贡献收入（线性 30+22r）天然限流后，r5+ 仍稳定提供
   4~10 倍于修炼的日收益——v30 的 ×6.2 曲线被整条旁路，且 r9 溢流同时灌「仙元」与「道境经验」双货币，
   DAO_TIERS（100~12000 阈值、声明"不随修为绑定"）被一两轮闭关秒满。
3. **P0 两枚**：驯服结算调用不存在的 `Battle.victoryTame`（驯服必软锁）；
   拍卖「造化仙丹」底价 15000 vs 售价 350000（minRealm 还比坊市低两境）——零风险低买高卖。
4. **经济**：黑市赌袋 r<3 彩头 m_gupian（面值 6000）锁死低境正期望（v30 堵漏堵反了方向）；
   sinkCurve 封顶 3^8 使 r9 终局灵石 sink 相对坍缩至收入的 4%；宗门职位按「当前贡献」判定，
   花贡献即降职丢长老加成。
5. **战斗**：精英词缀「不灭/魔棘」只在普攻路径接线；偷梁换柱偷到敌方身上的增益敌方读取端不存在；
   被控时凝神可净化束缚（E67 漏网）；法相追击绕过攻防状态；雾战闪避法诀侧缺失；
   洗练升星 ★1~3 死路；回灵 mp=0 永久失效。
6. **UX**：离线收益藏在默认折叠日志里（放置游戏的"回家仪式"归零）；音效默认全关
   （Ambience 系统对多数玩家不存在）；道侣/结拜只有弹窗+一行日志。
7. **日常负担**：满配洞府每日 12+ 次纯仪式点击（浇水×8、摸兽×N、求签、聚灵、下令）。

## A 节奏与激励重校（用户点名：游玩速度/升级速度）

### A1 修为曲线 ×6.2 → ×5.4（EXP_BASE 重排）
- `game-data.js` `EXP_BASE: [70, 380, 2350, 14700, 91800, 570000, 3540000, 22000000, 137000000, 850000000]`。
- 实算效果：闭关节奏下周目 5~6 年 → **≈3 年至飞升**；r8+r9 占比 49% → 34%；
  每境耗时 r0≈26 日 → r9≈180 日（闭关口径），前期不变、后期淤塞疏通。
- 联动：`docs/playbook.md` 经济节、verify-game/v3/v6 等境数种子全数重算更新（以 layerNeed 实算为准）。

### A2 悟道/溢流汇率重构（旁路→阀门）
- `wuDao` r<9：`20×80×eco` → **`baseGain(p)×2.5`**（自随乘数缩放，永不超过 ≈7.5 天修炼量/次）；
  弹窗文案同步。r9 维持仙元 1000（与修炼折算自洽）。
- `addInsight` 溢出 r<9：`spill×80×eco` → **`spill×baseGain(p)×0.125`**（与悟道同汇率 2.75×eco/点）；
  r9 维持 spill×50 仙元。
- **r9 三处双喂拆除**：`addExp` 溢流 / `addInsight` 溢出 / `wuDao` 不再 `DaoSys.gain`
  ——道境经验回归"职业行为积累"声明口径；仙元独享。
- 仙元溢流播报节流：`xianyuan % 50 < daoGain` 恒真刷屏 → 每 ≥500 或每日志去重。
- 听讲实耗一日：`act-sect-listen` 补 `Time.add(1)`（文案本就"听讲一日"）；
  配合 A2 后实测算：悟道环路全程贡献 ≈ +10~15% 主动收益（阀门），不再旁路曲线。

### A3 世界大事重定时（激活"世界活性"支柱）
- 首现 `10+rand(0,4)` 年 → **`2+rand(0,2)` 年**；后续 `y+18+rand(0,12)` → **`y+1+rand(0,2)`**。
- 旧档一次性重掷：无 history 且 nextEventYear>4 → 重掷至新首现窗（`_evResched34` 标记防重复）。
- 效果：一周目 2~4 场大事，12 类事件+次年回响+NPC 牵连真正进入玩家视野。
- verify-v15 断言随新窗更新。

### A4 离线收益重做
- 效率 0.4 → **0.6**；上限 30 日 → **120 日**（1 真实分钟=1 游戏日不变；仍低于在线效率，无刷点）。
- 配合 E1 离线小结弹窗（收益可见性）。
- verify-v12 离线断言随新参数修订。

## D 经济平衡（断套利 + 终局 sink）

  pill_zaohua base 15000→**140000** 且 minRealm 4→**6**（对齐坊市门槛，落槌转卖期望归负）；

  中奖统一 `matQty×2.5`；重算 EV：低福缘微负、满福缘微正（福缘投资回报保留）。
- **D3 sinkCurve 封顶 8→10**：r9 终局灵石 sink 相对收入从 4% 回到 ≈13%，登仙境钱有处可去
