## 一、B1 状态与收尾链竞态（E200~E205）

- **渡劫失利偷袭时序（E201，同族第 12 处）**：pendingDao 与 afterAction 先行、偷袭 400ms 后才开战——叩问弹窗与节庆相撞、pendingDao 被提前消费。对齐 dungeon E59：开战在前、afterAction 在后，偷袭战收尾链自然承接节庆与叩问。
- **成熟田虫害死角（E202）**：careCore 的 `remaining<=0 continue` 把顺手除虫一并挡在成熟田外，而 checkPest 照样上虫、harvest 照罚——只有惩罚没有出口。除虫前移至熟田判定之前（浇水业绩口径不变）；renderPlots 熟田「收 获+除 虫」两钮并存。
- **Daily.resetIfNew 第 0 日 coercion（E203）**：`(p[key]||-1)===t` 在第 0 日恒失配——同日反复判新（E175 同族残留单源地基）。改严格比较；消费方核验 auction/xian 行为不变。
- **续波重置漏连击层与连携势（E204）**：上一波五层连击（+20%/层）与法诀「势」（势尽 +15%）跨波全额滚存。七字段清单抽 `Battle.waveReset()` 单源并并入 combo/lastSkillTag/skillChain/skillSeq 四字段——此后新增跨波字段只改一处。
