四、Bug 修复（全库审计 + 四路探查核实，二十二处）
  1. 拍卖落标退款吃灵石获取加成——带增益时故意落标反而净赚（改原额入账）。
  2. 悬赏「声望赏格」纯展示从未乘算（真实入账）。
  3. 洞府扩建先扣灵石后查材料，缺料白扣（先验料再扣款）。
  4. 炼丹极品「当炉翻倍」在入包之后才乘二——袋中只得一枚、日志按两枚记账（先判定后入包）。
  5/6. 宗门职位「长老 气血+10%/防御+10%」与磐岩谷宗门气血/防御加成从未生效（接入属性总线）。
  7/8. 装备与词缀的「灵力%」「身法%」（丹心玉佩、迅捷等）从未生效（接入）。
  9. 属性明细「身法」功法来源恒为 0（键名 speedPct→spdPct）。
  10. 强化成功率表 3:90 是死档——+3→+4 白送必成（+3 起逐级递减回归设计）。
  11. 炼器失败日志显示基础成器率而非含炼器室的实际值。
  12. 剧情战遁走不回调剧情——主线/自动修炼永久停摆的软锁（补回调）。
  13. 宗门大比遁走可无限免费重赛到夺魁（遁走即止步结算）。
  14. 遁走成算用敌方原始身法，精英「迅影」/「迟滞」不参与（改结算后口径）。
  15. 敌方被缚回合跳过时不复位防御标记、不衰减增益——「防御+冰封」白吃一回合减伤。
  16. 轻身丹「闪避 +10%」从未生效。
  17. 祭符伤害不吃狂暴/虚弱状态（改统一攻击口径）。
  18. 灵石不足时 spendStones 先把中/上品打散仍返回失败（先验总额）。
  19. removeItem 可把库存减成负数（数量钳制）。
  20. 浇水/花朝对总生长期打折——临熟浇水等于当日催熟（改剩余天数口径）。
  21. 离线回拨作物熟期使「过熟廿日减半」永不成立；且日更系统离线全停（去回拨 + 逐日补结）。
  22. 无效宗门 id 时整次渲染崩溃（兜底）。
  另：登天塔祝福三选一洗牌有偏（sort 随机法），改 Fisher–Yates。
