# 《凡人问道》v18「大成」大版本更新总结

> 本次为「工程 + 修复 + 玩法 + 内容 + 视觉 + 音频」六位一体全面大升级。
> 存档全程向后兼容：v1~v17 老档读取时经版本链迁移自动补齐全部新增字段，进度丝毫无损。

---

## 〇、工程地基（阶段〇）

- **git 版本控制**：项目首次纳入版本管理，全程 30+ 次提交可追溯。
- **ES 模块化**：8800 行单文件拆分为 `js/core`（14 模块）+ `js/data` + `scripts/build.mjs` 构建脚本；
  开发在模块中编辑，构建产出 `game.js` 保持零依赖分发形态。
- **全局错误捕获**：`window.onerror` + `unhandledrejection` 兜底，异常只 toast 提示不断游戏。
- **存档双写校验**：写临时键 → 读回验证 → 写正式键，杜绝存档半写损坏；写失败明示玩家。
- **数值集中 `GameData.BALANCE`**：战斗/突破/属性/驯服/修炼/经济/强化七大类常量集中配置。
- **migrate 版本链**：单体迁移函数重构为 `MIGRATE_STEPS[]` 逐级执行，记录 `_migratedVersion`，
  未来新版本只需追加步骤。
- **验证脚本治理**：`test:v7`、`test:v8` 接入 npm scripts；Chrome 路径自动发现；新增 `test:all` 一键全量回归。

## 一、致命 bug 与漏洞修复（阶段一）

1. **主线 4~9 章剧情不可达（最严重）**：`STORIES` 对象在 c3 后提前闭合，
   c4_open~c9_end 共 24 段演出 + 6 次章末抉择被错误嵌套进 `DAO_TIERS`。
   修复后游戏后半程 2/3 叙事恢复播放，问道录不再空白。
2. **渡劫回溯 SL 漏洞**：失败回溯因果从零成本改为每次 **孽障 +8**，无限重试被遏制。
3. **画符印钞**：每日画符成本递增（首笔 1×，每轮 +50%，封顶 5×），灵石无限膨胀终结。
4. **驯服假逻辑**：兽栏满时的 no-op（`luck = Math.min(10, luck)`）改为实装
   **驯熟练度 `tameSkill`**（0-100，影响驯服成功率 +10%/10点）。
5. **离线收益落地**：新增 `computeOfflineProgress()`——灵田按真实时间戳生长，
   现实 1 分钟 ≈ 游戏 1 日（封顶 30 日），不再与「离线亦生长」文案矛盾。
6. **装备实例化**：`p.equipped[slot]` 从字符串升级为 `{ id, enhance, affixes }`，
   强化等级随实例走；`Utils.eqId()` 兼容新旧格式，旧档自动迁移。
7. **NPC 战斗技能池**：24 位常驻修士按性情各配专属技能
   （孤傲→傲剑诀流血、温婉→杏林春风治疗、冷厉→寒刃破甲……），切磋恩怨不再普攻对轰。
8. **修为溢出保留**：圆满后溢出修为存入 `expOverflow`，突破时折半带入新境界，不再白白丢弃。

## 二、战斗系统深化（阶段二）

- **敌方 AI 状态机**：替代纯加权随机——濒死（<25%）优先治疗、残血（<35%）开铁壁、
  玩家带增益则驱散削弱、玩家残血则吸血斩杀、半血增伤咆哮；控制技能择机释放。
- **自动战斗 2.0**：符修自动战斗不再自废职业——自动祭伤害符（优先）与控制符。
- **种族克制**：七族循环克制（兽→草木→灵体→阴魂→人形→傀儡→虫群→蛇→兽），
  克制方伤害 ±15%，`GameData.speciesRelation()` 供 UI 展示。
- **灵兽技能实效化**：协战时真实施加毒/流血/减益（60% 衰减），不再是装饰文案。
- **浮动数字排队**：伤害数字自动错位（去重间距 <12%），多段伤害不再叠字。
- **玩家受击反馈**：受击震动（`player-hit` 动画）+ 低血警报，打击感补全另一半。
- **打击音效**：命中（短促冲击）/ 落空（气流）/ 暴击（金属脆响）/ 格挡（沉闷撞击）。

## 五、UI/UX 重制（阶段五）

- **对比度修复（WCAG AA）**：`--text-faint` 2.96→4.8:1、`--gold` 3.96→4.7:1、
  紧急提醒卡深红字改浅色（1.37→8+:1）。
- **字体内嵌**：Google Fonts 引入 **霞鹜文楷 LXGW WenKai** + Noto Serif SC，
  全平台统一书卷气质；字体栈优先级更新。
- **tooltip 组件**：纯 CSS 悬浮提示（深底浅字 + 箭头），替代原生 title。
- **移动端触控**：860px 断点按钮/页签≥44px 触控标准；480px 纵向布局优化。
- **可访问性**：弹窗 `role=dialog` + `aria-modal` + `aria-label`。
- **开始界面背景**：远山飞鹤 SVG 场景（渐变天色 + 层叠山峦 + 雾霭 + 飞星，8% 透明度）。
- **新手引导聚光**：每步引导自动高亮对应面板（金色描边 + 脉冲动画），告别纯文字找位置。
- **战斗界面对称**：主角剪影立绘（六大道各配持物：剑/丹炉/符/拳/阵旗/魔气），与敌方对称。
- **渲染优化**：`markDirty()` 脏标记分区渲染，减少全量 innerHTML 重建。
