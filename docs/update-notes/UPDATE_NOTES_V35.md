## 一、E P0/P1 缺陷批修（E131~E138）

- **切磋零成本刷好感（E131，P1）**：原无限次、零成本、败也 +2——连输 45 场可把任意渡劫修士刷到莫逆结为道侣，赠礼/论道/结交三套社交被免费切磋完全支配。现**每 NPC 每日限一场**；落败好感归零变动（以武会友，胜负皆不损交情），胜 +5 不变，「三胜指点」回归阶段性目标。
- **传承树「故物重携」死天赋（E132，P1）**：树 3 层「多带一件法宝」的 +1 被兜底条件 `!p2.bag[kept]` 自己堵死（自 v26 起实为零收益）。基础携带改无条件 +1 且置于树层效果之前，两路径叠加出真实的第 2 件。
- **legacy 全局档内存键错位（E133，P1）**：`writeLegacy` 直拼 `Save.KEY+key` 写 mem、read 按裸键读（E123 同族第 3 例）——隐私模式/禁存储下历世数/印记/传承树/前世编年整链每会话清零、`marksGiven` 去重失效（印记可重刷）。统一走 `Save.writeRaw`。
- **剧情演出键盘跳战（E134，P1）**：剧情战开场后 `Story.cur` 仍在（startBattle 只隐藏 modal 不清 cur），Enter/空格可把 idx 越过 battle 场景直接 finish——**胜负旗标（k3/k6/k8/k9 等）永久丢失**、依赖旗标的章末回响永不出现；investigate（细察）同样可越过，四枚线索旗标静默蒸发。键盘分支补 `Battle.active` 短路 + 场景类型守卫（与 skip() 自停集合对齐）。
- **重读剧情可真打战斗（E135，P1）**：问道录「重读」的战斗卡可点「迎 战」——真打一场、战斗计数/掉落/成就照单全收，且可无限重刷。`startBattle` 补 `readonly` 守卫；回顾模式渲染「此战已成往事」纯文本。
- **脏档物品 id 渲染崩溃（E136，P1）**：万宝阁出售区与功法待学典籍未判空（E23 漏两处）——脏 id 使两页签渲染永久崩溃且玩家看不见删不掉。两处补判空；导入存档顺带清洗未知 bag id（E197）。
- **bak2 回捞销毁活档（E137，P1）**：坐化收场的死档滚入 bak2 后，「回捞」先把当前活档 auto 覆盖成死档才被死档检查拦下——安全网自身成了销毁通道。`snapshotAuto` 跳过 dead 档；回捞前验死档拒绝；覆写前旧 auto 落 `auto_pre_bak2` 二级保险。
- **塔跳层赌约时序错位（E138，P1）**：赌约判定在 `nextFloor` 之后——下一层已开打才问「跳不跳」，接受后 `run.floor+=1` 抬高的是刚开打的这层：被跳层照发层奖（还按被抬高层计价）、最高层纪录虚增，**赌约成了稳赚不赔的正期望**。判定挪到进层之前，层奖/纪录/文案三者对齐。

## 二、C 战斗收口（E139~E143、E169~E173）

- **自动战斗治疗择优从未生效（E139）**：比较器读死键 `.heal`（治疗法诀的回复量字段是 `.power`，全表无 .heal）恒 0 空转，永远施放插入序第一个治疗诀——同时修了金身不灭与涅槃重生的玩家残血永远优先念 40% 的旧诀。比较器改读 `.power`。
- **镜像词缀漏接法诀护体（E140）**：精英词缀「镜像」（你每获得一项增益其攻击 +8%）原只认丹药/符箓/本命增益——罡气护体/剑气壁垒/残影步走旧 `B.buffs` 直写不经统一入口，永不触发。补 `mirrorProbe` 探针（不落 StatusFx，防防御双计），fresh 判定与续施去重对齐。
- **灵兽助战未接受击钩子（E141）**：助战一击可无声跳过「不灭」复活、「魔棘」对助战伤害零反弹（同一词缀时灵时不灵）。助战总伤（含蚀魂追加）统一走 `Battle.onEnemyHit` 结算。
- **灵兽跳级漏天生技（E142）**：物种技/精进判定原在升阶循环外做等值比较——4 级兽攒够 3899 经验一口 4→6、8 级攒两趟派遣 8→10，五阶天生技与九阶精进**终生漏发且无补救**。判定移入 while 逐级结算。
- **节庆与开战十处竞态（E143）**：`afterAction`（内含节庆检查）在前、`Battle.start` 在后——除夕年兽弹窗被后续开战静默丢弃（旗标已置不回滚，当年年兽凭空消失）、七类节庆弹窗叠开在战斗层上。explore×2 / world×4 / npc×3 / sect×1 十处统一改先 start 后 afterAction（对齐 dungeon E59 模式）。
- **多波妖群中间波白打（E169）**：中间波只发半额修为——灵石/掉落全无、悬赏/宗门/精英计数只认最终波（悬赏目标在波内时「亲手斩杀却不推进」）。补半额灵石+半额掉落（`rollDrops` 加 rate 参数）+逐波击杀计数。
- **续波意图断档（E170）**：多波续波只置空意图不重掷——每波首回合无「下一手」提示，读招博弈断档一轮。续波补 `planIntent()`。
- **魔棘反伤致死对尸体结算（E171）**：反伤把玩家打到 0 血后原流程照走敌方回合（对尸体完整结算一轮）。行动前与主行动后统一查存活，直接进收尾判定（塔心不灭/元婴代死/defeat 单源）。
- **敌方侧死常量接线（E173）**：`ENEMY_CRIT_MULT`、`DMG_RAND_MIN/MAX`（敌方向）、`SPECIES_COUNTER.bonus`（双方克制 ±15% 字面量）接线集中配置——v34 C9 漏网的最后一批，调参不再有「改了不生效」的陷阱。

## 三、D 经济平衡

- **拍卖功法池按品阶重定价（E147）**：grade5 九天雷神经底价 9000/minRealm2，比 grade3 大衍神诀 12000/minRealm3 还便宜且门槛低两境——金丹期 1.2 万灵石锁定毕业功法。现 grade3≥10000/r3、grade4≥20000/r4、grade5≥45000/r5，池内品阶底价/门槛单调（进 price-audit 门禁）。
- **赌袋胜率钳顶（E148）**：`25+luck×4` 无上限——满气运端（天机果+装备+气运 150）胜率 100%、期望 +6% 静默转正，而审计门禁只采样 luck∈{0,10} 恰好绕开转正区间（平衡点 93.3% ≈ luck 17.1）。胜率钳 ≤75%，采样扩至 [0, 10, 17.5, 23]。
- **拍卖 r0 死池（E174）**：LOT_POOL 最低门槛 minRealm 1 使练气期 `usable` 恒空、回落全池——整期锁死不可拍品在 r0 原样复现（E41 漏网）。m_danfang 降 minRealm 0。
- **第 0 日拍卖哨兵（E175）**：中标 `until=0` 与开局 `day=0` 相撞（`until < day` 恒假）——第 0 日内可对同一拍品无限复购的逻辑炸弹。改 `until=-1`。

## 四、E 玩法升级包（薄弱系统重铸——本版「大升级」主体）

### U1 社交经济重铸
- **赠礼/结交/道侣心愿成本锚定双方境界较低一方**（E176）：原按 NPC 境界指数膨胀——NPC 自行涨到 r8 后一份寻常礼 130 万灵石换 +1~3 好感，偏好系统对高境修士事实失效、好感度到莫逆后所有礼数全是负反馈。
- **投其所好取对应类别「价最低」一件**：原取包里首个命中（可能无声烧掉毕业法宝/保命金光符）。
- **行游在外真实化（E180）**：原只挡偶遇、江湖页照常可互动（旬轮换沦为纯摆设）。现结交/赠礼/论道/切磋对行游修士禁用并明示「行游在外，旬末方归」，江湖页加「行游在外」tag——世界节律第一次真实可感。

### U2 斗兽场重构（E177）
- 实测原分布：初始兽胜率 21%、中期 24%（对 1.6 倍赔付**期望 -61%~-66%，中前期是纯亏陷阱**），仅毕业兽 +32%，且界面零胜率信息——系统事实两极分化：毕业兽印钞、其余人永久避坑。
- 重构：胜算由养成度（力量/阶数/蜕变/亲昵四维加权）单点定夺——初始 ≈44%、中期 ≈57%、满养成 ≈77%（毕业兽正期望保留、日限三场封量）；**面板实时显示胜算预估与 62.5% 保本线**——押不押、押多大，第一次有据可依。

### U3 日常归一（E178）
- **一键行权吸收一键照料**：原两张皮——行权不浇水不抚兽不除虫、照料不采收不领赏不补种不聚灵，玩家每天要点两个「一键」才办完日常，虫害两个都不管。现行权吸收照料核心（共用 `CaveSys.careCore`，行为与一键照料严格一致），全日常单入口。
- **聚灵扣款明示**：原在一键行权里静默扣款（后期每日 137 万灵石的支出藏在家务按钮里）。现首日弹一次确认（今日聚灵/以后都聚不再询问/今日跳过），花钱决策回到明面上。
- **今日修行卡补全**：完成度计入浇水/抚兽/虫害——原卡面「4/4 事毕」时洞府里还有三件事。
- **照料虚报修正（E154）**：成熟田不计入浇水业绩（原「浇水 8 块」实有一半零效果凑数）。

### U4 多周目修正
- **道胎正名（E149）**：树 11 层「道胎（出生即练气二层）」原实发 layer=2（练气**后期**），与描述差一档、与来世预约「生而近道」同质撞车——归位 layer=1（练气中期），两者拉开一档。
- **轮回印记首世生效（E180）**：首世玩家靠图鉴大成/塔 30/飞升攒下的印记「全属性永久 +X%」原当世一个百分点不加（`p.reinc` 为空不回写）——而开始界面就能开轮回镜，新玩家最先看到的就是这条失义承诺。现首世建立轻量 reinc 使承诺当世兑现；`firstLife` 标记隔离前世专属语义（「轮回初醒」仍须真正兵解、前世洞府机缘仍只属转世者）。

### U5 仙界圆满体验（E150~E152）
- **AutoCult 圆满引导**：真仙圆满态选「攒修为」目标永远不可达（修为轴已顶）——开启时即刻拦截并指路仙元目标；挂机途中飞升致 exp 目标失效时自动转攒仙元，不再每 0.28s 空转刷日志。

- **连续闭关守护链补 dao-modal（E152）**：转道后渡劫失利弹出的叩问大道在场时，闭关循环原继续烧灵石与岁月（与 AutoCult 守护不对称）。

### U6 门禁扩容（E166/E181）
- **price-audit 四路扩容**：①宗门贡献兑换汇率横向检测（面值/贡献 >60 报警）；②画符现金流分境界×符道境扫描（变现期望 vs drawPrice）；③拍卖功法池品阶底价/门槛单调性；④赌袋采样扩至 [0,10,17.5,23]。本类「结构性套利」自此进门禁。
