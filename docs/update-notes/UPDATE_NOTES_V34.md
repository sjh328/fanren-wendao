## 一、A 节奏重校（游玩速度与升级速度——v34 主轴）

### A1 修为曲线 ×6.2 → ×5.4
- v30 校准目标「全程 12~20 游戏年」的实算漏计了闭关 1.6× 效率与多源修为入账：实玩一周目仅 **5~6 年**，而 r8+r9 两境白占纯修炼时长的 **49%** 且期间无任何新机制——典型 dead time。
- `EXP_BASE` 重排为 `[70, 380, 2350, 14700, 91800, 570000, 3540000, 22000000, 137000000, 850000000]`（每境 ×5.4）。
- 效果：闭关节奏全程 **≈3 年至飞升**，r8+r9 占比降至 34%；前期每境不变，后期淤塞疏通。境界种子相关旧测试全部随新曲线重算。

### A2 悟道/溢流汇率重构——从「旁路」到「阀门」
- 实锤：听讲（300 贡献→+8 感悟）→ 悟道（20 感悟→**1600×eco 修为**）折算汇率 80×eco/点 ≈ **219 倍单日修炼产出**，整条 ×6.2 曲线被贡献环路旁路；r5+ 稳定提供数倍于修炼的日收益。
- 悟道收益改 `baseGain(p)×2.5`（≈7.5 天修炼量/次），**自随乘数缩放**——无论版本怎么改曲线，悟道永远是「主动加餐」而非第二主粮；感悟溢出（addInsight spill）同汇率改 `baseGain×0.125/点`。
- **r9 双货币双喂拆除（E117）**：真仙圆满后的修为溢流/感悟溢出/悟道原本同时灌「仙元」与「道境经验」——道境经验（DAO_TIERS，阈值 100~12000，声明口径「职业行为积累、不随修为绑定」）被一两轮闭关秒满，剑仙境等行为轴形同虚设。三处转换点全部拆除 DaoSys.gain，仙元独享。
- 仙元溢流播报节流（原 `xianyuan%50<daoGain` 在 daoGain>50 时恒真，长闭关每轮刷一条）。
- **听讲实耗一日**：补 `Time.add(1)`——文案「听讲经义一日」此前却零时耗，与修炼白抢同一天。
- 实测算：修复后悟道环路全程贡献 ≈ +10~15% 主动收益——阀门，不是旁路。

### A3 世界大事重定时——唤醒沉睡的「世界活性」
- 实锤：首现钉在 10~14 年、此后 18~30 年一遇（v30 按「12~20 年周目」校准），而实玩一周目仅 5~6 年——**十二类世界大事对正常玩家整周目零触发**，灵疫药价、宗门大战、次年回响等整套机制事实死亡。
- 首现改 **2~4 年**（r3~r5 段），此后 **1~3 年一遇**；旧档一次性重掷（`_evResched34` 防重，已有大事记录的档不动）。
- 效果：一周目 2~4 场大事，仙界长岁持续供应；世界活性整根支柱自此上线。

### A4 离线收益重做
- 实锤：在线挂机每 0.28s 推 3 游戏日，而离线上限 30 日×四成效率——挂夜 8 小时只得 12 有效日，「回家礼物」薄得近乎羞辱（放置激励倒挂）。
- 上限 30→**120 日**、效率 0.4→**0.6**（1 真实分钟=1 游戏日不变；仍显著低于在线效率，无刷点）。
- **云归·离线小结**（E1）：归来一纸四行账弹窗（离线时长/修行精进/灵泉涌出/弟子历练/仙界访客）——离线收益不再藏在默认折叠的日志红点后；灵泉灵石数并入离线聚合（原只报「照常涌出」不给数额，对不上账）。

## 五、E 沉浸感与体验

- **音效默认开（E2）**：原 `sfxOn:false` 且开关藏在顶栏齿轮——多数玩家从未听到过任何声音，Ambience 系统事实不存在。默认值翻转（显式存过偏好的老档照旧尊重），突破音效门槛 tier≥4→≥1——进境即有声光，前期最高频的仪式时刻不再静默。
- **道侣/结拜仪式感（E3）**：结为道侣/义结金兰原是「确认弹窗+一行日志」——情感线的峰值时刻用最低仪式感交付。复用现成轮子补全屏异象（realmShow 换色）+公告+稀有音效，不加新演出系统。
- **拍期将止紧迫感（E4）**：余日 ≤3 红色 danger tag+「明日易主」——玩家不再分不清「还有 10 天」和「明天截止」。
- **建议减负（E5）**：左栏「当前建议」与顶部 focus strip 主/副卡同目标去重——圆满/飞升/叩问/斩三尸/碎片合成等同一信息一屏三见的时代结束。
- **日志过滤语义（E6）**：「系统」组剔除见闻（info）——找突破/大事记录不再满屏见闻。
- **对比度（E7）**：`--text-faint` 加深一档（4.8:1→5.8:1），12px 小字正文低分屏可读。
- **剧情自动播放（E8）**：翻页间隔按当页字数自适应（2400+字数×12ms 封顶 8s）——千字长页打字机未完即被翻走的自毁演出就此终结。
- **引导补漏（E9）**：新手引导补「问道页是主线总览」一句（最重要的方向感入口缺席）；横竖屏文案改 render 时惰性求值（转屏重看不再出旧分支）；玩法说明尾部补设置面板交叉引导。

## 七、G 工程地基

- **多页签并发提示（G1）**：两页签各持独立内存态交替覆写同一 auto 键，后写者全量覆盖先写者、用户零感知——`storage` 事件检测他页改动，提示一次。
- **AutoCult abort 补落盘（G2）**：读档/返回开始界面触发 abort 后，当轮 `Cultivate.normal()` 照常执行但成果无人落盘——循环内检测已停即补 `autoSave(true)`。
- **newGame 离线守卫（G3）**：新档显式跳过离线结算（`_skipOfflineOnce`），不再只依赖 `day===0` 的隐式巧合（防未来 factory 改动误结算旧档 auto）。
- **sw.js 陈旧 query 清理（G5）**：release bump `?v=N` 后旧 `game.js?v=N-1` 条目永不清除（activate 只删旧 CACHE 名，同 cache 内旧 query 条目保留）随版本累积——activate 时按当前 CORE 清单重整，删除主资源旧变体。
- **DAO_YUN 合并缓存（G6）**：`compute/activeDaoYun` 每次调用新建 concat 数组——挂机热路径一轮修炼 4~6 次 compute 即 8~12 次无谓分配，提为惰性缓存。
