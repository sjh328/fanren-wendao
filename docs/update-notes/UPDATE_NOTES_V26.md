V26「拨云」

一、移动端 · App-Shell 化（换方案，不再打补丁）
  · ≤860px 游戏改为「壳」结构：顶栏、行动横幅、底部导航、游历记载工具条全部常驻视口，
    #tab-content 成为唯一滚动容器（100dvh + overscroll-behavior:contain）——
    顶栏资源条不再随手势滚走，彻底告别页面级双滚动与 iOS 橡皮筋打架。
  · 战斗盒同样壳化（≤860px）：立绘与条目定高、战报区内滚，普攻/法诀/防御/道具/遁走与
    自动战斗/策略/速度全程一屏可见——长战报不再把操作顶出屏幕。
  · 焦点条窄屏纵向堆叠，两卡不再并排挤压；日志工具条改单行横滑。
  · 触控体检：去系统高亮、按钮压感反馈、键盘焦点可见。

二、可读性（用户截图问题根修）
  · 「提醒」副卡由 14% 透明度朱红叠纸底（对比度 ≈1.5:1，不可读）改为朱砂实底卡
    （深底浅字，实测 ≈8.9:1），与主线墨金卡形成「墨 / 朱」同语系。
  · 进度条文字改「重墨晕影」：低填充时白字落在浅色空轨上依然清晰（战意/真元 0 值另配墨字）。
  · 辅助文字色整体加深一档（--text-faint #7a6e58 → #6d614c）。

三、任务表达与引导
  · 行动横幅升级：主线卡显示「目标 2/3 · 步骤文字（进度）」与「前往 · 宗门」目的地副行——
    点「前往」之前就知道去哪、差多少。
  · 「前往」直达 + 鎏金闪光：切页后自动滚动定位到目标卡片并高亮 2 秒
    （如问道页直达「青峰山」地图卡、直达炼丹炉），「去了但不知道干嘛」消失。
  · 问道页步骤行：序号圆标 + 数值目标微进度条 + 前往带目的地标注。
  · 修瑕：问道页展示章改用「境界追认后」的有效章——境界领先时不再显示早已完结的旧章
    （与行动横幅、顶栏卷章此前相互矛盾）。
  · 页签滚动位置记忆：切走再回来，长列表回到原处；移动端新增「回到顶部」浮钮。

四、Bug 修复（全库审计 + 实机走查，十六处）
  1. 祭炼强化对已穿戴装备只写共享档不写实例——属性永不提升、灵石白花（穿戴实例 enhance>0 后必现）。

  3. 聚灵加速弹窗与日志被转义成 \${...} 代码原文（去转义）。
  4. 自动修炼「攒修为/限时」两种目标输入框恒隐藏且无联动——两目标自 v6 起形同不可用（现随类型显隐）。
  5. 离线天数绕过 Time.add：年龄出现 16.08… 小数、跨年结算全跳过（改逐日回放；寿元尽照常坐化）。
  6. 黑市破财分支下品灵石不足时分文不扣却照写「灵石 -X」（新增 Bag.spendStonesMax 实扣实报）。
  7. 转世传承树第三层「多带一件法宝」被下一行无条件覆盖回 1（天赋自此真实生效）。
  8. 调息化毒条件恒真，「胎息」境界特性形同虚设（练气 5 点 / 其余 3 点）。
  9. 宗门长老令文案「至明日」实际白得两日（until 对齐文案）。
 10. 放归「护持中」灵兽后副战位悬挂（同步清位）。
