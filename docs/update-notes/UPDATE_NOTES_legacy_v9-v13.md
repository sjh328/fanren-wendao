## 〇〇、v13「万象更新」：九大板块全面升级

### 一、战斗系统深化
- **状态效果系统（StatusFx）**：中毒 / 灼烧 / 流血（回合损血）、破防 / 迟滞 / 虚弱（属性削减）、束缚 / 冰封（跳过回合）、金光（减伤）与四种增益状态；敌我双向施加，战斗面板实时显示状态标签与剩余回合。
- **敌人技能池**：全部 47 种怪物配置专属技能（毒蛇淬毒牙、树妖根须缠绕、铁甲犀铁壁、蝠群嗜血狂叮、阴灵摄魂夺魄、凶猿擂胸咆哮……），按权重施展，取代单调的普攻/重击二选一。
- **精英狂暴**：精英血量低于四成进入狂暴——攻 +30%、杀招更频繁，名字红光脉冲、血条变色警示。
- **连击系统**：普攻连续命中累积连击层（每层 +4% 伤害，上限五层），受击中断，面板显示「连击×N」。
- **自动战斗**：战斗中一键开启——残血自动服药、敌蓄力自动防御、有蓝自动放最强法诀；战斗速度三档（×1 / ×2 / 极速）随时切换。
- **战斗增益丹**：狂暴丹（攻 +30%）/ 铁骨丹（防 +40%）/ 轻身丹（身法闪避）/ 明目丹（暴击），战斗中使用。

### 二、装备强化 + 炼器 + 套装（坊市新区块）
- **祭炼强化**：已穿戴法宝可强化 +1~+10，每级 +10% 数值属性；成功率逐级递减，+7 起失败跌一级；【强化石】可保必成；消耗灵石与玄铁矿。
- **炼器坊**：14 条炼器配方，消耗材料锻造装备——天级神兵（天问剑 / 太乙道袍 / 龙魂玉）与套装件只能炼器获得。
- **套装系统**：玄天套装（防御线：防 +15% / 血 +10%）与赤霄套装（攻击线：攻 +15% / 暴击 +5%），集齐三件成套，左侧面板实时显示套装效果。

### 三、洞府经营（新页签，筑基解锁）
- **聚灵阵**：洞府五层，每升一级修炼效率 +4%、灵田 +1 块（至 8 块）、兽栏 +1 位。
- **灵田种植**：播下种子（六种：灵草 / 灵芝 / 冰魄花 / 雪莲 / 炼魂花 / 星辉草），按游戏日生长、离线亦生长；成熟收获，过熟廿日收成折半。

### 四、灵兽系统
- **驯服**：战斗中将可驯妖兽（兽 / 蛇 / 虫群 / 草木 / 灵体；人形与傀儡不可驯）打至两成血以下，出现「驯服」按钮——成功率受福缘与境界压制影响。
- **养成与助战**：出战灵兽每回合四成几率协助攻击，并提供物种被动（兽→攻击、蛇→暴击、草木→气血、虫群→闪避、灵体→修炼效率），随品阶与等阶成长；喂【妖兽内丹】升阶（1~10 阶）；洞府兽栏寄养。

### 五、内容大扩充

## 〇〇·三、v16 道境独立晋升：职业境界不再绑定修为

**核心变革**：六大道境（剑心/丹道/符道/般若/阵道/魔道六境）**彻底脱离修为境界**——每重有独立的【道境经验】阈值（100/300/800/2000/5000/12000），由职业专属行为积累，经验攒满即晋一重。练气初期的修士也可以把道境修得很高，反之境界高而不践行本道，道境依旧原地踏步。

**六大职业专属经验来源（18 处钩子）**
- 剑修·剑意：普攻命中 +12、会心/剑心通明 +20、参悟功法 +8~20
- 丹道·丹火：炼丹成功 +25 / 失败 +8、服丹 +3
- 符修·符道：祭符 +12、画符每张 +4
- 体修·体魄：受击 +4、格挡 +8、防御行动 +6、调息 +10
- 阵道·阵道：抢先布阵 +20、秘境推进 +15、修炼/闭关聚灵 +1~10
- 邪修·魔性：吞噬精元 +20、击杀 +6、孽障缠身 +2、化功修炼 +2~20
- 共通：参悟功法按是否为职业专属功法 +8 / +20

**界面**：左侧道境面板显示当前重数效果 + 经验条（当前/下一重阈值）+ 下一重名称与需求 + 获取方式提示；晋升时金色公告 + 破境音效。

**平衡与兼容**
- 经验曲线与获取速率匹配原节奏：一重约 8 场战斗，六重约 500~800 场高级战斗——低境界肝道境可行但成本高昂，形成自然的软性递进。
- 老档迁移：按旧「境界解锁」规则将已获道境折算为对应经验（元婴剑修 = 800 剑意），进度丝毫无损；新档从零积累。
- 全部 30+ 处道境特效调用点（战斗/炼丹/画符/渡劫/属性）接口不变，自动跟随新层数。
