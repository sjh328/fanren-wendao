# 更新日志 · v21「焕新」——全方位体验大升级

> 定位：v20 在玩法广度上已是完整体；v21 不加新系统，而是把**每一个维度的质感**整体拉高——
> 修掉影藏交互 bug、重排信息架构、给剧情以演出、给引导以直达、给行动以反馈。

---

## 阶段〇 修瑕（交互 bug 修复）

- **剧情战层级修复**（实锤 bug）：此前「迎战」开启剧情战时，剧情浮层（z135）持续压在战斗弹窗（z100）之上，
  玩家**完全点不到普攻/防御**。现在开战即暂隐剧情浮层，战斗结束（胜/负皆可）浮层归位、无缝续演战后旁白。
- **公告不再遮演出**：境界突破/主线完结等居中公告，在剧情/战斗/弹窗打开时会**即时上移至顶栏下方**
  小字号播放，关层后自动归位中央。此前公告与剧情文字同屏重叠、互相糊字。
  - 实现上新增 `UI.syncAnnouncePos()`，在 Story 开/关、Battle 开/关、Popup 开/关五处接线。

## 阶段一 界面骨架重排

- **顶栏资源条**：新增三枚常驻徽章——`卷 X / 9 章`（主线章程）、`◈ 灵石（下/中/上）`、`⚔ 战力`，
  滚动数字动画接入；任何页面随时可读资源与进度。
- **灵石显示三处去重**：此前左栏 / 乾坤袋 / （新顶栏）三处重复，现收敛为顶栏一处；
  左栏回归纯粹的角色面板，乾坤袋回归纯粹的物品栏。
- **中央双列栅格**：修炼 / 问道 / 洞府三页签在 ≥1280px 宽屏下卡片并排铺满，
  消灭中央大片留白；`修行`与`今日修行`左右并列，一屏见全貌。
- **菜单分组**：七入口按「记档」（成就/人物志/战斗回顾/生涯）与「系统」（存档/说明/回开始）两组重排。

## 阶段二 修炼页升级

- **仙途十境路线图**：修炼页顶部新增十境节点条（练气→真仙），已过境界实心、当前境界鎏金脉动、
  各境界小字标注当前层（初期/中期/后期/圆满）——来路与前程一图可读。
- **行动浮字**：修炼/闭关所得在按钮上方飘起渐散（`修为 +790`，灵机事件附注），Actions 有感；
  沿用 v20 性能开关门控（`amb-anim` 关闭时不显示）。

## 阶段三 剧情演出升级

- **打字机逐字演出**：旁白/对话按每帧 3 字逐字显现；点击剧情区任意处或翻页键**一键补全本页**（视觉小说惯例）。
  - 设置中心新增「剧情逐字演出」开关（默认开）。
  - 问道录回顾重读**直接全显**（重读旧文不再逐字等待）。
  - 自动化回归环境（`navigator.webdriver`）自动跳过逐字，保障文本断言确定性。
- **抉择卡升级**：甲/乙/丙编号圆章 + 选项卡式布局 + 底部「抉择即因果」注脚；
  回顾重读时**前尘所选**会被虚线标记，重读时一目了然当年怎么选的。

## 阶段四 引导直达

- **「当前建议」每条可带「前往 ›」**：突破/主线/丹毒/宿敌/转世等建议直接跳转对应页签，不再让玩家自己找入口。
- **新增三类日常提醒**：黄历未签 / 灵田已熟 / 悬赏可领赏——写进当前建议，错过不再无感。
- **今日修行聚合卡**（修炼页）：黄历求签 / 聚灵加速 / 灵田 / 悬赏板 / 当日节庆，五事一行一状态
  （已办绿点 / 可办红点脉动 / 未办灰点），右上角 `X / N 事` 总览，行尾「前往 ›」一键直达。

## 阶段五 玩法增补

- **闭关结算报告**：出关一纸小账——轮次 / 修为进益 / 丹毒化解 / 历时 / 境界变迁（连续闭关进阶时）。
  圆满冲关闭关不弹报告（天劫自有一幕演出，不再叠窗）。

## 阶段六 视效统一

- **天骄榜行补血**：榜行不再只有名号与境界——新增关系标签（萍水/友善/道侣…）、
  战力对比条（与榜首相对）、与你的层差（高 N 小层 / 低 N 小层 / 与你并肩），对手含金量一眼可辨。
- **卡片进场 stagger**：栅格页签卡片按序轻浮入场（0.3s 内完成，不打断操作）。
- **弹窗开合过渡**：全部 modal 淡入 + 内容盒上浮，反馈统一。
- **性能开关全门控**：`设置 → 数字动效`关闭时，入场/过渡动画一并关闭（`body.anim-off`）。
- **移动端 480px 复核**：修复新顶栏在小屏被旧位置规则误隐藏的问题（改为类名定位）；
  标题防折行、徽章紧凑化；小屏顶栏只留日期，隐去寿元/存档文案。

## 阶段七 质量收口

- **verify-v10 新增 V 组 10 项断言**（47/47）：剧情战层级、公告让位、顶栏资源条、仙途路线、
  修炼浮字、打字机（自动化跳过 + 逐字 + 补全三态）、今日修行卡、建议跳转、闭关结算、菜单分组。
- **修复 verify-v10 X2 组的 UI.popup 桩泄漏**：该桩未恢复导致后续所有真实弹窗被吞（V 组排查中定位）。
- **修复悬赏置空条目的空引用隐患**：领赏后 `bounties.list` 条目为 null（v13 遗留设计），
  新增的引导提示与今日修行卡首次出现未判空读取——已加判空（回归实测抓获）。
- **回归链防挂死加固**：E2E 截图统一加 15s 硬超时（渲染器偶发失速不再挂死整条链）；

  主力套件浏览器加 `--disable-gpu --disable-dev-shm-usage` 稳定化参数。
- 九套全量回归 + `node --check` 构建校验；`index.html` 缓存号递增 `?v=35`。
