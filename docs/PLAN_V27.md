# V27「归一」计划 —— 不加新玩法，把系统织成网

> 用户诉求：① 手机端适配还要再优化；② 每个功能、玩法之间联系太小、不够紧密；
> ③ 界面设计和布局大升级；④ 仔细找 bug；⑤ 全方位优化、面面俱到；⑥ 对现有功能玩法大升级（不新增）。

## 〇、定位

v26 把移动端做成了一只「壳」，v27 要做的是把壳里的世界连起来：全库审计发现四类结构性断裂——
① 百分比键漏乘（宗门 hpPct/defPct、装备 mpPct/spdPct 从未生效）；② 定义了却无消费方的死代码
（洞府炼丹房 pillBonus、演武场 train、声望赏格 bountyBonus、长老令半边）；③ 单产出端资源
（声望只有布施一个来源）；④ 日更钩子只挂在行动收尾（离线 30 天分文不进）。
v27 的主线就是把这张网织严，顺带修掉四路探查（bug 猎查 29 条候选 / 联动矩阵 / UI 架构 / CSS 审计）核实后的
二十二处真实缺陷，并完成一轮信息架构与视觉层级的大升级。

## 一、A 系统联动升级（玩法之间长出关系，不新增玩法）

- **声望经济闭环**：悬赏领赏真实吃 `RepSys.bountyBonus`（×1.15/×1.3/×1.5，此前只在 UI 标注）；
  新增三处声望产出端——悬赏践诺 +1、宗门差事践诺 +1、红尘劫相助 +2；顶栏新增「誉」徽记常驻；
  义声卡文案同步实情。悬赏板赏格展示值同步按 ×声望×连锁 预览（与实发一致）。
- **洞府死代码激活**：`CaveSys.pillBonus`（+5%/级）接入 `CraftSys.rate`——洞府等级第一次真正提升成丹率；
  `builds.train` 演武场（攻防 +2%/阶）接入 `Stat.compute` 与属性明细「洞府（聚灵/藏宝/演武）」行；
  炼制坊丹炉区标注「洞府 +N%」。
- **长老令补全**：「开炉演武 · 门派任务与悬赏酬劳 +50%」此前只有悬赏半边生效——`SectSys.rewards` 补上另一半。
- **道心代价联网**：普通战斗败北心魔 +3（切磋/大比/塔/秘境/剧情战各自的轻惩罚分支不在此列）。
- **弃道重修名副其实**：转道清空原道 `daoExp`——此前重拾原道立即继承全部道境层数。
- **离线日更结算**：抽离 `Game.dailySettle(p, auto)`（节庆/大比/共修/窥伺/登顶日赏/访客/虫害/灵泉/图鉴），
  行动收尾与离线回放共用；离线逐日补结，互动节庆自动从简（灯谜隔日想、河灯静观、除夕守岁），
  灵泉只入账不刷屏，道侣心愿需互动故留待在线。
- **成就计数接线**（七项永锁成就全部打通）：无伤之道 / 雷霆之速 / 越境斩敌（battle victory）、
  破招行家（破招分支）、驯兽大师（驯服按物种去重）、秘境征服者（通关按 realm 去重）、画符千张（drawTalisman）。

## 二、B 界面设计与布局大升级

- **顶栏三组式**：身份资历（卷章）｜家资（灵石 + 声望「誉」徽记）｜战力岁月（⚔ + 时间），组分隔竖线，
  徽记加图标与配色语义；移动端 chips 组间距放宽。
- **左栏信息层级重排**：身份卡 → 宗门 → 核心属性（三条件 + 四维 + 八格属性，气血构成并入格）→
  道行状态 → **当前建议**（从栏底提前到中段，指引更显眼）→ 装备法宝/境界特性/大道/前世折叠。
- **问道页大改**：章节进度轨下新增一屏总览条（支线了结 x/21 · 章助缘 x/10 · 残玉共鸣 x/9）；
  奇遇录 21 张支线卡由一锅平铺改为四组归位——「可结案 / 进行中 / 已了结 / 未启」各带计数标题；
  **往章助缘跨章补领**（此前章末即作废）。
- **江湖页**：每行 NPC 增加交情量表（-100 宿敌 ↔ +100 莫逆，中点刻度，一杆读亲疏）。
- **文案实情化**：玩法手册「声望」「离线」两条改为与新行为一致。

## 三、C 移动端适配再优化

- **触控目标统一 ≥40px**：战斗自动/策略/速度钮、法诀/道具子面板、引导「前往」、火候选择、
  背包页签、设置入口、抽屉入口、子页签、折叠头、弹窗 ✕ 全部抬高度（火候 40px 规则置于 S9 之后确保生效）。
- **键盘让位**：`visualViewport` 缩放量实时写入 `--kb` 并挂 `html.kb-open`，弹层据此上移——
  iOS 软键盘不再盖住底部弹层里的输入框（平时贴底弹层零变化）。
- **横屏/矮视口**：新增 `@media (orientation: landscape) and (max-height: 520px)` 压缩分支——
  顶栏收单行、横幅紧凑、日志 clamp、底导航降高，内容区不再被挤成负数。
- **刘海避让修复**：v24 的 `padding-top: env(safe-area-inset-top)` 被 v25 的 padding 简写静默覆盖——
  避让并入简写（`calc(8px + env(...)) 12px 8px`）。
- **字号缩放真实生效**：样式表全 px 使根字号三档形同虚设——`applyFontScale` 改用根级 `zoom`。
- **滚动链封闭**：#log/#bt-log/.bt-sub/.codex-list/#popup-body/.tutorial-box/横滑轨道全部 `overscroll-behavior: contain`；
  弹窗 max-height 改 dvh 口径。
- **性能**：body 去 `background-attachment: fixed`（≤860）；血条危急脉动改预置光晕层走 opacity；
  主按钮流光改 transform 推进；弹窗毛玻璃 ≤860 降为纯色（放低端机一马）。
- **可读性**：10~11.5px 级辅文整体抬到 ≥11.5/12px；问道轨渐隐死选择器 `.rail` 纠正为 `.quest-rail`；
  死令牌 --bg-soft/--panel-2 清理；v20 死规则（battle-box 88vh）与重复块收敛；
  存档文本码/自动战斗下拉等输入统一 16px 防 iOS 聚焦缩放；设置面板可滚动；
  中屏 861~1180 栅格第一行改 `minmax(0,1fr)`（左栏内容不再把右栏挤出视口）。
