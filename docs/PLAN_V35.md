# PLAN_V35「淬锋」

> 主题释义：淬火砺锋——六路深审（战斗/经济/修炼节奏/世界日常/UX/工程）复核后定稿。
> 三枚 P0 实锤（符修画符印钞、宗门贡献倒挂环、渡劫成功误走失利尾段）是本版主锋；
> 社交经济被免费切磋单策略支配、斗兽场中前期纯亏陷阱、双一键割裂，三处薄弱玩法重铸；
> 其余三十余条真 bug 批修（E128~E190 段位）与两处门禁扩容。**不新增大块内容，以纠偏与重铸为主。**

## 审计结论摘要（定性）

1. **经济**：①画符 `Time.add(1)` 使当日成本阶梯每次归零——防印钞设计结构性失效，符修单击净赚 231×eco/日（r4+ 约 11~15 场战斗收入）；②宗门 800 贡献兑 2 仙晶卖店 45,000 灵石（同表其余 9~50 面值/贡献），构成 ×6 印钞环；③拍卖功法 grade5 底价 9,000 低于 grade3 的 12,000 且门槛低两境；④赌袋胜率无钳制，满气运端转 +6% 正期望而 price-audit 只采样 luck∈{0,10}。
2. **渡劫**：成功分支无 return 坠入失利尾段——每次非仙劫突破成功都折寿 10 年（与同函数「寿元上限提升」播报自相矛盾）、道侣说「劫输了」、宿敌可趁「渡劫虚弱」偷袭满血突破者、pendingDao 误置。
3. **社交**：切磋零成本、无限次、败北也 +2 好感且只回两成血——连输 45 场可把任意渡劫修士刷成道侣；赠礼成本按 NPC 境界指数膨胀（高境 130 万/份）而收益递减；「行游在外」只挡偶遇不挡江湖页任何互动——三套社交机制被免费切磋完全支配。
4. **多周目**：传承树第 3 层「故物重携」是死天赋（兜底条件吞噬树层加成）；「道胎（练气二层）」实发后期、与来世预约「生而近道」同质撞车；legacy 全局档在隐私模式下写读键名错位（E123 同族第 3 例）——印记/树层/编年整链清零。
5. **战斗**：塔跳层赌约在 nextFloor 之后结算（被跳层照发层奖+纪录虚增=免费正期望）；灵兽助战未接 onEnemyHit（不灭跳过/魔棘免反伤）；镜像词缀漏接法诀护体/残影步；自动战斗治疗择优读死键 `.heal` 恒 0；必杀/本命被控消耗路径在 try 外（busy 永锁窗口）；多波妖群中间波零灵石零掉落零计数。
6. **世界/日常**：节庆检查在 afterAction 内、十处「先 afterAction 后 Battle.start」的竞态可让除夕年兽静默蒸发；收集悬赏领赏预览漏 ×2（显示腰斩）；连签跨断签不刷新、重置无提示；一键行权与一键照料两张皮+聚灵静默扣款。
7. **UX/工程**：剧情演出 Enter/空格可跳过剧情战与细察（胜负旗标永久丢失）；问道录重读可触发真实战斗刷计数；脏档物品 id 令万宝阁/功法页永久渲染崩溃；bak2 回捞可把当前活档覆盖成死档。

## A P0 实锤（三枚）

### A1 符修画符：成本挂产量单源定价（E128）
- 病灶：`craft.js` 每画一符 `Time.add(1)` → `Math.floor(p.day)` 必变 → `_drawCount` 恒归零，1×→5× 防印钞阶梯结构性不可达；成本恒 40×eco，r4+ 符池 8 种均价 75.4、产量期望 8 张，变现 271×eco——**净 +231×eco/日**。
- 处方：`drawCost` 改按当前符池动态定价——`round(期望产量EV × 池均价 × 0.5 × stoneEco)`，期望产量含朱砂境 ×2 概率与符仙境 +2；倒卖期望归负（约 -13%），自用（符箓战斗 4.6 倍爆发价值远高于面值）依旧划算；同日连画阶梯保留（修正为行动前日戳判定，语义回归）。UI 侧按钮显示价同步走新 drawCost。

### A2 宗门贡献兑换：断倒挂环 + 领赏日限（E129）
- 病灶：`{ item: 'm_xianjing', cost: 800, qty: 2 }`——2 枚仙晶卖店 45,000 灵石，面值/贡献 125 vs 同表 9~50；宗门任务无限接、cult 任务一次修炼即满，环路上限不受控。
- 处方：①`m_xianjing` 兑换 cost 800→**8000**（对齐 pill_taichu 档，面值/贡献回落 12.5）；②`SectSys.claim` 补**每日领赏上限 6 桩**（`_claimDay/_claimCount`，跨日重置），UI 差事页显示余量。

### A3 渡劫成功收尾归位（E130）
- 病灶：`tribulation.js` 成功分支（非仙劫段）无 return，坠落至 328 行起失利尾段——`Time.cutLife(p, 10)`、道侣「劫输了」安慰、`NpcSys.tribAmbush` 偷袭、`p.pendingDao = true` 全部在成功路径执行。
- 处方：折寿/道侣安慰/偷袭/pendingDao/收尾弹窗整段移入 `else`（失利）分支；成功分支自持收尾（关弹窗、afterAction）。v29 设计原意「天劫**失利**折寿十年」归位。

## D 经济平衡（E147~E148、E174~E175）

- **E147 拍卖功法池按品阶重定价**：grade5 底价 ≥45,000（minRealm 5）、grade4 ≥20,000（minRealm 4）、grade3 ≥10,000（minRealm 3），池内相邻 grade 底价单调；已按坊市/宗门同档价锚定。p2 落槌即毕业功法白菜价的问题归零。

## E 玩法升级包（薄弱系统重铸——本版「大升级」主体）

### U1 社交经济重铸（E176）
- **赠礼/结交成本锚定玩家**：`30×stoneEco(NPC境界)` → `30×stoneEco(min(玩家境界, NPC境界))`——高境 NPC 不再索要 130 万/份的贡品；投其所好偏好消耗改为从对应类别中**取价最低一件**（不再盲收第一件可能是毕业装）。
- **行游在外真实化**：江湖页对 `isAway` 的修士禁用互动按钮（显示「行游在外，旬末方归」），旬轮换从纯摆设变为真实的江湖节律。
- **指点门槛正名**：「三胜指点」不变败记录保持，但切磋日限后 3 胜需要 3 日——指点回归为阶段性目标而非连点战利品。

### U2 斗兽场重构（E177）
- **对手分段**：对手 power 分布随己方养成度分段（低养成兽遇弱旅），蒙特卡洛复算目标：初始兽胜率 45~55%、毕业兽 70~80%——从纯亏陷阱变为风险可控的赌局。
- **胜率预估**：斗兽面板按分段公式显示「胜算预估」与赔率（仿秘境意图预演），玩家第一次有决策依据。
- **保本线显示**：1.6 倍赔付的 62.5% 保本线在 UI 明示。

### U3 日常归一（E178）
- **一键行权吸收一键照料**：act-daily-all 扩展为「求签+聚灵+采收+补种+**全田浇水**+**全兽抚摸**+**除虫**+领赏+差事」全日常单入口（浇水/抚摸收益规则逐项复用 CaveSys 现有实现，不重写第二份）；洞府页「一键照料」保留为就地入口（二者共用同一 helper，行为严格一致）。
- **聚灵明示**：一键行权内聚灵扣款前置弹一次性确认（「今日聚灵将耗 X 灵石」+「本次及以后不再询问」记忆项），花钱决策不再藏在家务按钮里。
- **今日修行卡补全**：完成度计入浇水/抚兽/除虫——卡面「N/M 事」与洞府实际待办一致。
- **照料虚报修正**（E154）：成熟田不再计入浇水业绩。

### U4 多周目修正（E149、E179、E180）
- **道胎正名**：树 11 层「道胎」desc 与实现统一为「出生即练气**后期**」？——不，取描述为准：`layer = Math.max(p2.layer, 1)`（练气中期），与来世预约「生而近道（三层）」拉开一档，两者定价不再同质。
- **轮回印记首世生效**（E180）：首世玩家攒下印记（图鉴大成/塔 30/飞升）当世即享——grantMarks 在 `p.reinc` 为空时建立轻量 `{ marks: min(30, earned) }`，轮回镜文案承诺「全属性永久 +X%」当世兑现；兵解路径不受影响。
- **传承树故物重携**（E132 同项，升级侧：树 3 层从死天赋变为真实第 2 件法宝）。

### U5 仙界圆满体验（E150~E152）
- **AutoCult 圆满引导**：r9 圆满态选「攒修为」目标时 toast 指引改攒仙元（修为轴已顶）；挂机小结在圆满态改报**仙元增量**（start 时记录 startYuan）。
- **单轮闭关口径**：r9 圆满预估改报仙元（`gain ÷ 46110`）；圆满态单轮闭关也走结算报告（「仙元 +X」），与连续闭关报告对称。
- **闭关守护链补 dao-modal**：与 AutoCult 守护对齐，叩问大道弹窗在场时连续闭关挂起。

### U6 门禁扩容（E181）
- **price-audit 扩容**：①宗门兑换汇率横向检测（面值/贡献 > 60 报警）；②职业产出现金流扫描（画符 sell-EV vs drawCost 分境界、炼丹同法）；③拍卖池相邻 grade 底价单调性；④赌袋采样 [0,10,17.5,23]；⑤**per-action 现金流榜**：枚举可循环动作按净灵石/日排序 Top10——新失衡自此进门禁。
- **check-actions 盲区**（E166）：SKIP 补 `scripts/`；`act:` 三元形态纳入对账正则。
- **balance-sim**：对齐本次经济参数复跑，输出各境节奏无离群段留档。
