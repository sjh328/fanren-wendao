## 〇、定位

v26 给移动端造了「壳」，v27 把系统织成了「网」——但两轮都以「补丁式」改良为主，界面的**骨架**没动：
移动端顶栏仍占三行、底部八个页签挤作一团（前期五个是死锁🔒）、桌面中栏大片留白、视觉语言逐版本堆叠缺乏统一 token。
v28 要做一次「骨架级」重塑，同时修掉一个现网实锤的 P0 层叠陷阱。

**P0 已确认根因（截图 bug）**：`#game-screen` 带 `position:relative; z-index:1`（style.css:89）形成层叠上下文，
移动端抽屉 `#panel-left/right`（z:80）被困在其中；而 `#drawer-backdrop`（z:70）是 `#app` 直属子元素，
在 body 层 70 > 1 → 遮罩压住**包括已打开抽屉在内的整个游戏画面**，点哪都是遮罩。
修复：把 `#drawer-backdrop` 移入 `#game-screen` 内（遮罩 70 < 抽屉 80 同域比较）。
已在 390×844 视口复现 → 修复 → 命中测试 `elementFromPoint` 返回面板本体（默认与 110% 大字号两种情况均验证）。

## 一、A 界面重塑（本次主菜）

### A1 移动端 ≤860px：一屏一事
1. **顶栏三行并一行（≈52px）**：
   - 左：**身份徽章**（道号+境界小字，点击=开道途抽屉）；
   - 右：灵石 chip、⚔战力、⚙、☰道途、🎒乾坤（图标钮 40px）；
   - 卷章/声望/岁月/寿元 chips 移入**道途抽屉头部身份卡**（本来就是身份信息）；
   - 气血/修为 mini 双细条贴顶栏下沿全宽常驻（血线一眼可见，替代原 chip 内藏）。
2. **行动卡合并**：主线卡 + 提醒卡两块高卡合并为一张行动卡——主行（主线/要务+前往），次行（提醒小字+前往），
   高度近乎减半；无主线时主行让给里程碑，与现逻辑一致。
3. **底栏 8 键 → 5 键 + 「更多」面板**：
   - 常驻：修炼 / 问道 / 游历 / 坊市 / 更多；
   - 「更多」弹**底部面板**（新组件 #more-sheet，含遮罩、40px 格子）：洞府 / 江湖 / 宗门 / 功法 四大页签
     + 快达格（悬赏板 / 灵田 / 灵兽 / 秘境 / 天塔 / 奇市 / 万宝阁 / 炼制坊…）；
   - 红点聚合：四页签任一有红点 → 「更多」亮红点；面板内各格红点照常；
   - 未解锁页签在面板内灰显带锁角标（底栏不再出现整排🔒）；
   - `tab:sub` 深链、Guide 前往、dots 红点源全部不动（act-tab 兼容）。
4. **视觉**：底部面板与弹窗共用圆角/遮罩 token；sheet 弹入动画（transform 合成器友好）。

### A2 桌面 ≥861px：一屏全貌
1. **中栏填充**：`.grid2` 之后追加**快捷传送行**（常用目的地 chips：悬赏板/灵田/天塔/秘境/万宝阁…红点透传）；
   修炼页在宽屏下「修行+今日修行」双列已有，矮内容页签（修炼/问道）下方留白由日志区默认展开吃掉
   （桌面日志默认高度上限上调，可收起）。
2. **左栏瘦身**：桌面端「当前建议」与中栏行动横幅信息重复——桌面下建议卡下沉到折叠区，
   行动横幅成为唯一「现在做什么」出口（移动端建议仍在抽屉内常驻）。
3. **右栏乾坤袋**：物品卡双列网格（≥1280px 三列），筛选行吸顶；物品卡统一高度对齐。
4. **总线刷新（双端共用）**：建立设计 token——`--radius`（卡 14/弹层 18/钮 10）、`--sp`（8px 基线间距组）、
   `--shadow`（三级投影）；卡片描边/纸面/标题字距统一；按钮四态（默认/悬停/按压/禁用）统一由 token 派生；
   清理逐版本堆叠的重复规则（v13/v19/v22/v25/v26/v27 的移动端补丁块归并）。
