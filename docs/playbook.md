## 核心循环

## 战斗（修罗场）

- 五键：普攻 / 法诀（战盘四招）/ 防御 / 道具 / 遁走 + 职业必杀（真元 0~8）+ 本命战技（3/6/9 阶）。
- **敌方意图**：名字旁「下一手 · ⚔/✦/💤」实时公示——蓄力时防御化解、会心可**破招**、防御有**反击**。
- 资源条：战意（伤害+0.4%/点）、真元（普攻+1 会心+2 防御+1）、连击（+4%/层）。
- 状态：中毒/灼烧/流血/破防/迟滞/虚弱/束缚/冰封/金光 双向施加；精英词缀 ◆ 汲血/魔棘/迅影/坚甲/血性/不灭/瘟疫/裂魂/镜像/雷皮/守财/群狼。
- 自动战斗 ⚙策略：血线/必杀偏好/符箓保留；速度三档；快键 1~5。

## 养成五树

1. **修为树**：修炼 → 境界特性十境 → 道境六重（独立经验）→ 大道六职业。
2. **装备树**：坊市/炼器 → 强化+10 → 词缀（◆前缀/◈后缀）→ 套装四系 → 传承/分解 → 本命法宝喂养十阶+觉醒战技。
3. **功法树**：学习 → 参悟满层 → **大成奥义** 30 部 → 道韵 12 组（双满层共鸣）。
4. **灵兽树**：驯服 → 内丹十阶 → 五阶天生技/十阶第二技 → 蜕变王号 → 派遣/斗兽。
5. **江湖树**：结交 → 送礼偏好/论道 → 切磋段位三胜指点 → 结拜/道侣（共修+心愿）→ 个人线 16 人 → 雷台了断。

## 世界活性

- **天时**：夜（敌攻+15%·夜获）/ 雨（雷+20% 灼烧-20%）/ 雾（机缘↑闪避↑）；**四季**：孟春修炼+10%/仲夏成符+2/季秋丰收+1/隆冬蛰伏。
- **节庆**：上元（灯谜）/ 花朝（灵田-2日）/ 中元（点灯消孽）/ 中秋（赠礼×2）/ 除夕（年兽战）。
- **天下大势**：每百年八类事件（魔域/讲道/秘境/大战/灵潮/兽潮/仙门收徒/陨星）。
- **宿敌**：结怨 → 偷袭/截胡 → 雷台了断夺宝；**深耕**：单图 20/50/100 次三重加成。

## 经济

- 修为 ×4.6^境 / 灵石 ×3.8^境 / 定价 ×2.2^境——同境战胜 ≈ 2.4 天纯修炼产出。
- 灵石 sink：闭关开销/强化/炼器/洗练/本命喂养/营造/拍卖/布施/斗兽押注。
- 印钞防护：画符日成本递增 ×1.5 封顶 5×；符箓时价买卖同步；经济审计脚本 `price-audit.mjs` 归零。
