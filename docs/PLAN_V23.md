# v23「顺手」QoL 提速 + 防回归计划

> v22 完成信息架构与移动端大适配后,再扫一轮全项目,本轮主题是**顺手**——
> 把高频重复操作的点击次数降下来、把 v22 修掉的两类存量坏块用工具锁死、清掉遗留物。
> 数值与经济依旧零改动。

## 阶段 A 操作提速

- **A1 万宝阁批量购买 ×5**:丹药/法器/材料/种子类商品增加「×5」按钮
  (`ShopSys.buyMulti`,逐次按当前市价扣款、灵石不足自动停,功法仍单购)。
- **A2 连续探索 ×5**:游历·舆图每张地图卡新增「连续探索 ×5」——最多五次历练,
  遇战斗/剧情/弹窗/天下大事自动暂停(玩家处置后可再点),每次均按 2 日推进。
- **A3 一键行权·自动补种**:一键行权在采收后,若灵田有空田且囊中有种子,
  自动按持有量最多的种子播满空田(种子唯一用途即播种,无保存顾虑),小账注明。

## 阶段 B 提醒与信息

- **B1 奇市提醒进当前建议**:黑市开市中(剩 N 日)→ `shop:odd`;
  拍卖行拍期余 ≤10 日且有拍品 → `shop:odd`。错过开市/漏拍不再无感。
- **B2 成就页排序**:每分类内**未完成(带进度)在前、已完成在后**,刷成就一目了然。
- **B3 战斗回顾留三场**:战斗回顾从"仅上一场"升级为**最近三场**切换查看(会话内存,不进存档)。

## 阶段 C 移动端信息密度

- **C1 顶栏迷你条**:≤860px 顶栏日期旁新增**气血/修为双迷你条**(抽屉收起时也能一眼看血线)。

## 阶段 D 防回归工具(锁死 v19/v22 两类坏块)

  迷你条、三场回顾、CSS 体检各一项。
