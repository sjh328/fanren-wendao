# v22「归一」全方位大升级计划

> 诊断结论(现状通读 ui.js/game.js/quest.js/style.css/guide.js/tutorial.js/九套回归):
> ① **坊市页签是杂物间**——万宝阁、悬赏板、黑市、炼丹、符坊、祭炼、洗练、本命、炼器、拍卖、布施
>    十一个区块堆在一页,是"杂乱"的最大来源;② **洞府/游历**也各有 4~5 类内容平铺;
> ③ **移动端只是"竖着排"**——860px 以下三栏变一列,角色长面板排在最前、菜单垫底,
>    无底部导航、无抽屉,手机上要先滚过整块道途面板才看到操作;④ **功能分散**——
>    悬赏在坊市、黄历在游历、灵田在洞府,引导(v21)已聚合但页签归属未变;
> ⑤ 弹窗无点遮罩关闭、左栏信息无折叠层级;⑥ 玩法缺一个"宗门归属感"的高潮点。
>
> 版本主题:**归一**——信息架构归一(子页签)、操作入口归一(移动端底部导航+抽屉)、
> 日常归一(一键行权)、引导归一(新知提示)。数值与经济零改动。

---

## 阶段 A 信息架构重组(核心)

**A1 子页签框架**:新增 `Game.subTab`(按页签记忆),`act-tab` 支持 `"tab:sub"` 深链写法;
   页签内容头部渲染子页签 chips(横向可滚动),`renderTabContent` 按 `activeTab+subTab` 分发。

**A2 坊市拆五**:
   | 子页签 | 内容(从旧坊市平铺迁入) |
   |---|---|
   | 万宝阁 | 丹药/法器/功法/材料/种子 采买、出售、灵石兑换 |
   | 炼制坊 | 炼丹炉、符坊(符修)、炼器坊 |
   | 祭炼堂 | 强化、词缀洗练、本命法宝喂养 |
   | 悬赏板 | 悬赏任务板 |
   | 奇 市 | 黑市、拍卖行、布施 |

**A3 洞府拆三**:洞府主楼(聚灵阵+营造)/ 灵田 / 灵兽(兽栏+斗兽场入口)。

**A4 游历拆三**:舆图(地图卡+深耕)/ 秘境(秘境+碎片合成)/ 天下(天下大势+黄历求签)。

**A5 全站深链迁移**:Guide.tips、今日修行卡、QuestSys.GO、焦点条等 `go` 值改写为
   `shop:bounty`、`cave:farm`、`map:world`、`map:realm`、`cave:beast` 等;锁定页签子级同样受锁。

**A6 红点迁移**:悬赏可领→坊市红点;灵田已熟→洞府红点;天下大事待抉择→游历红点(原有)。

**A7 问道/宗门/江湖/功法保持单页**(内容量适中,不强行拆分)。

## 阶段 B 移动端大适配

**B1 底部导航**:`#tabs` 在 ≤860px 由 CSS 定位为固定底部栏(横向滚动+safe-area),
   主内容区预留 padding-bottom,不再需要滚回顶部切页。
**B2 双抽屉**:顶栏新增「☰ 道途」「🎒 乾坤」两枚移动端专用按钮(桌面隐藏);
   ≤860px 时左栏/右栏变为侧滑抽屉(默认收起,遮罩点击即合),渲染管线不变。
**B3 底部弹层**:≤480px 时通用弹窗/大道/天劫/战斗框改为近全屏底部弹层样式。
**B4 焦点条 sticky**:移动端焦点条吸顶,随时可见"现在该做什么"。
**B5 触控复核**:子页签 chips ≥40px、底部导航 ≥44px、抽屉内按钮触距复核;
   `viewport-fit=cover` + `env(safe-area-inset-*)` 全接线。
**B6 引导适配**:Tutorial 高亮目标在抽屉内时先开抽屉再高亮。

## 阶段 C 玩法深度(全部挂靠既有系统,不另起炉灶)

**C1 宗门大比**:入宗后每五年一届;三轮车轮战(对手强度随境界),
   胜场累进发奖(贡献/灵石/气运),三连胜魁首记入 flags 并上成就;失败亦有安慰奖。
   挂靠 SectSys + Battle 既有对战,游历记载入卷,问道年表入档。
**C2 一键日常**:今日修行卡新增「一键行权」——按 求签→聚灵→采收灵田→领悬赏
   顺序自动执行可办事项,弹一纸小账(办了什么、得了什么);无可办则提示。
**C3 修炼预估**:修行卡显示「距圆满约 N 日」,让"还要肝多久"一眼可读。
**C4 秘境路径预览**:秘境节点改为预生成队列,界面显示当前抉择+前方两层预览,
   肉鸽式抉择从"盲选"变"险中求稳"。

## 阶段 D 剧情与引导

**D1 首遇新知**:Guide 新增 one-time 提示库(首次装备法宝/丹毒过半/结下宿怨/秘境开放/
   宗门开放/洞府开放/大道可择/大比召开…),以 ✦新知 置顶进「当前建议」并入日志,只提示一次。
**D2 飞升结语**:白日飞升后一次性结语演出(仙门之后的留白式收笔),答谢三百年主线。
**D3 引导文案焕新**:新手引导五步文案改写(适配子页签+移动端布局),三分钟清单同步。

## 阶段 E 交互与体验修缮

**E1 弹窗关闭**:通用弹窗右上角 ✕ + 点击遮罩关闭(按取消结算);关键确认框不受影响。
**E2 左栏折叠分组**:装备/属性明细/境界特性等用原生 `<details class="fold">` 分组折叠,
   常驻项(身份卡/核心条/建议)不折叠,长面板一眼分层。
**E3 细节**:子页签切换滚动复位、`tab-switch` 过渡延续到子页签、
   游历记载工具条小屏换行优化、数字动效门控全覆盖复核。
