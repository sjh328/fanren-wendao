# V26「拨云」计划 —— 不加新玩法，把现有的一切磨亮

> 用户诉求：① 手机端适配换更好的方案；② 提醒条文字看不清；③ 任务表达不清、引导弱；
> ④ 仔细找 bug；⑤ 全方位优化；⑥ 对现有功能大升级（明确要求：不新增玩法与内容）。

## 〇、定位

v25「掌上乾坤」把移动端搬上了底部导航与双抽屉，但整体滚动仍是「文档流」形态：顶栏随手势
滚走、内容区与页面双重滚动、iOS 橡皮筋与固定元素互相打架。v26 不再打补丁，改为一次
**App-Shell 化**：手机上游戏就是一只「壳」——顶栏常驻、底栏常驻、中间内容区是唯一滚动容器。
同时修掉实机走查与全库审计发现的一批真实缺陷，并激活两套「代码已在、玩家从未见过」的现成
机制（炼丹火候、丹药品质），完成一次不加玩法的深度升级。

## 一、A 移动端 App-Shell（style.css，≤860px 生效，桌面零分叉）

- `#game-screen` 高度锁 `100dvh`（`100vh` 兜底），纵向 flex：顶栏（auto）/ `#layout`（1，溢出隐藏）/ 底部导航。
- `#tab-content` 恢复为唯一滚动容器（`overflow-y:auto` + `-webkit-overflow-scrolling:touch` +
  `overscroll-behavior:contain`），body 锁 `overflow:hidden`——单一滚动源，顶栏资源条永不滚走。
- `#log-wrap` 展开时定高内滚，不再撑开文档；`#focus-strip` 吸顶改为在滚动容器内吸顶。
- 战斗盒（≤860px）：`.bt-actions` 与激活的 `.bt-sub` 底部吸附——普攻/法诀/遁走不再被长日志顶出屏外。
- 触控体检：全局 `-webkit-tap-highlight-color` 透明 + 按钮 `:active` 压感；`.bar-text` 空条改深色。
- 底部导航回归文档流内 flex 尾部（去掉 position:fixed 的双滚动打架），高度实测收窄。
- 回到顶部浮钮：滚动容器下滑超过 1.5 屏时出现（移动端）。

## 二、B 可读性（用户截图问题）

- `.focus-alert`（提醒副卡）：文字原为 `#fce8e0` 压在 14% 透明度朱红叠米色纸底上 ≈1.5:1，不可读。
  改为**朱砂实底卡**（与主线墨金卡同语系）：深朱砂渐变底 + 浅米字，对比度 ≥7:1。
- 修炼页 480px 断点：主线/提醒两卡并排互相挤压 → 改纵向堆叠、行内布局、按钮右置，省一半纵向空间。
- `.bar-text` 在 0% 空条上白字压浅轨 → 有内容才白字，空条自动换墨色。
- `tip-line`、`--text-faint` 小字整体加深一档（#7a6e58 → #6f6350），长文阅读不费眼。

## 三、C 任务表达与引导

- 焦点条升级为「带进度的行动横幅」：主卡显示 `目标 2/3 · 拜入一座宗门（0/1）`，
  副行标注目的地（`游历 › 舆图`），玩家点「前往」之前就知道会去哪。
- `quest-goto` 直达后自动**滚动至目标卡片并鎏金闪光 2 秒**（UI.glimmer）：舆图直达定位到
  「青峰山」那张地图卡，炼制坊直达定位到丹方卡——「去了但不知道干嘛」消失。
- 问道页：每个目标步骤加微型进度条与步骤序号；「前往」按钮统一带目的地标签。
- QuestSys.focus() 返回结构化进度（idx/total/prog），焦点条与问道页共用同一数据源。

## 五、E 性能与体验优化

- autoSave 节流（上表 #15）——挂机链路最大热点。
- 页签滚动位置记忆：切页再回来，长列表回到原处（滚动容器内实现，桌面同样受益）。

- 全量回归与既有断言零破坏为前提：`.q-go/.guide-go/.focus-*` 等类名与关键文案全部保留。

## 六、F 现有玩法深度升级（不加新系统）

- **炼丹火候**（v18 已实现数值、从未有入口）：炼制坊每张丹方卡内联「文火/武火/文武交替」
  三档火候选择，成丹率实时预览（丹道高阶提升契合率）；批量连炉不受火候影响，行为与旧版一致。
- **丹药品质激活**（v18 判定后被丢弃）：上品 → 丹道感悟 +5；极品 → 当炉产出 ×2 + 丹道感悟 +10，
  批量结算汇总品质计数——「丹香清正，可遇不可求」落到实处。
- 修炼页行动横幅、问道页步骤卡同步换新（A/B/C 的 UI 部分即体验升级主体）。
