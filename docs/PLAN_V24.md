# v24「归心」——主线牵引 · 界面减负 · 剧情补全 · 引导织网 · 经济闭环 · 移动端打磨

> 全项目梳理结论：v22 归一了信息架构、v23 提了操作速度，但三大结构性问题仍在——
> ① **约 12 个弱关联系统（求签/灵田/悬赏/奇市/拍卖/布施/斗兽/节庆/图鉴/声望/道韵/灵兽派遣）全靠 Guide 提醒和红点维持存在感，没有被主线与成长回路自然牵引**；
> ② **剧情「虎头蛇尾」：反派暗线 mid2 只有 c1/c2 有（c3~c9 七章断档），16 个抉择旗标只写不读**；
> ③ **交互欠账：江湖行 10 按钮、灵兽行 8 按钮平铺，红点逻辑五处各算各的，破坏性操作确认不一，渲染函数藏副作用，后期灵石收入×3.8ᵃ 对回收×2.2ᵃ 通胀，45 个 0 价物无法回收**。
> 本轮主题「归心」：让所有系统回到主线周围，让所有信息回到该在的位置。移动端与 CSS 同步补课。

## 阶段 A 主线牵引（功能归心）

- **A1 章助缘（九章每章一条可选支目标）**：主线卡新增「助缘」行——不挡章末推进，完成后额外领赏，
  把本轮未入主线的系统逐一织进剧情动机：
  c1 求签一次 / c2 驯服灵兽一头 / c3 开辟洞府 / c4 布施行善一次 / c5 祭炼强化一次 /
  c6 参与天下大事一次 / c7 拍卖行竞得一件 / c8 个人线推进一幕 / c9 激活一条道韵。
  领赏制（`p.quest.bonus` 自愈字段，无需迁移）；计数器 `signs/tames/donates/enhances/eventJoins/auctionWins` 在各系统落点 +1。
- **A2 布施迁家**：布施三档从坊市·奇市迁至**江湖·义声卡**（行善消业与江湖声望同卡，主题归位）；
  奇市卡只余黑市+拍卖，副题改为「黑市 · 拍卖——非常之法，非常之时」。
- **A3 声望接线（复活半死系统）**：`RepSys.priceMul` 真正接入万宝阁购买价（声望≥80 九折 / ≥30 九二折 /
  负声望溢价）；义声卡展示声望六档进度与效果说明（坊市买价 / 悬赏品质）；出售价不受声望影响。
- **A4 祭炼堂·熔铸回收**：新增回收区——列出囊中品阶≥3 且坊市无回收价（0 价）的法器，
  分解得灵石+玄铁矿；`Bag.salvage` 对 0 价物按品阶兜底价四折回收，45 个「高分战利品变背包垃圾」就此终结。
- **A5 道韵协同卡升级**：功法页道韵卡逐条展示——组合两功法各自层数 x/3、激活状态、道韵效果、
  差最后一级时明示「参悟 xxx 至三层可成韵」。

## 阶段 B 界面交互（减负与统一）

- **B1 红点统一源 `UI.dots()`**：页签+子页签红点全部收敛到单一计算函数，新增覆盖：
  问道（支线可结案）、宗门（任务可领赏/大比开赛）、洞府·灵兽（寻宝归来）、游历·秘境（碎片≥9 可合成）、
  江湖（个人线可续谈）、坊市·奇市（黑市开市/拍期将止）；子页签按钮同样渲染红点。
- **B2 江湖 NPC 行重构**：主行只留高频四钮（结交/赠礼/论道/续谈），切磋/结拜/道侣/指点/背刺/化解/雷台
  收进「恩怨与机缘 ▾」折叠——10 钮平铺成为历史，危险操作与日常操作分级。
- **B3 灵兽行重构**：主行留出战/护持/喂内丹/蜕变，抚摸/派遣/放归收进「照管 ▾」折叠。
- **B4 万宝阁减负**：五类商品分组折叠（丹药默认展开）；出售区独立折叠（默认收起，摘要显示可售总值），
  售出行按价值降序——买与卖不再 40+ 行平铺一页。
- **B5 宗门卡序归位**：本宗任务卡置顶（新玩家第一屏就是可做的事），派系→大比→兑换依次跟随；
  删除 `cmdBtn` 死代码，长老令并入任务卡标题行；贡献值走 `fmtNum`。
- **B6 防重入锁**：全局分发器按元素加 `_busy` 锁——处理期间同一按钮的重复点击被忽略
  （弹窗按钮、战斗按钮各自独立元素不受影响），双击双扣就此封死。
- **B7 破坏性操作确认统一**：存档弹窗内「删除」、万宝阁「全售」、「一键卖凡品」、黑市「赌一手」
  全部补确认弹窗（显示涉事金额）。
- **B8 渲染副作用归位**：`RankSys.dailyReward`、`CaveSys.visitorEvent/checkPest/springDaily`
  从渲染函数迁至 `Game.afterAction`——「打开页面才结算」改为「行动即结算」，渲染恢复纯函数。
- **B9 「该做什么」三套去重**：Guide 建议移除求签/灵田/悬赏三条日常（今日修行卡+红点已覆盖），
  腾出位置给**支线可结案**与**个人线可续谈**两条新知——建议栏重新聚焦主线/紧急/新知。
- **B10 CSS 清理与移动端补课**：删除 `.top-chip` 死样式段与重复 `.top-meta2` 规则、被 v22 整体覆盖的
  v20 480px 弹窗规则；顶栏 `safe-area-inset-top`；≤860px 隐藏 `.tab-sep`（底部导航不再被分隔线挤爆）；
  ≤480px `.btn-sm` 触控目标 38→42px；底部导航右缘渐隐遮罩。
- **B11 杂项**：游历·舆图「连续探索 ×5」加可见副文案（不再只有 title）；拍卖/黑市行内提示可见化抽查。

## 阶段 E 经济与成长闭环

- **E1 聚灵加速解封顶**：成本单源化为 `CaveSys.rushCost(p) = 120 × stoneEco(当前境界)`——
  练气~金丹价格不变（原 min(4) 封顶），炼虚起随 3.8ᵃ 曲线跟进，高境灵石有了日常去路；一键行权同源接线。
- **E2**（并入 A4）0 价物回收兜底。
- **E3 成就补档**：境界线补炼虚/大乘/渡劫三档（气运 12/14/16），头注释「三十项」改为实数。
- **E4 图鉴收集闭环**：五类图鉴（功法/法宝/妖兽/奇人/秘境）每类收集满 → 全属性永久 +1%（一次性，
  toast+announce），成就图鉴弹窗尾部显示各类收集进度——164 条目从此有收集回报。
- **E5 离线修行**：离线期在灵田生长之外，按 `修炼轮收益 ×40%` 折算修为（上限同样 30 日），
  回归时一条日志汇报——放置游戏名实相符；闭关/自动修炼语义不再混淆（离线≈半速自动修炼，不冲关）。
- **E6 天骄榜含金量**：榜行为你补一行「实战胜率参考：当前战力 ⚔N」（真实 Stat.power 展示，
  排序键保持境界制不动，避免经济与平衡连锁）。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 章助缘/新字段破坏老档 | `p.quest.bonus`、`p.flags.*` 全部走「用时自愈」模式，PlayerFactory 无需新迁移步 |
| 声望买价扰动经济审计 | 折扣仅作用于购买且上限 15%，price-audit 口径复核；出售价不动 |
| 移除 Guide 日常提示断掉旧断言 | 实施前 grep 九套 verify 脚本，文案断言同步更新到新载体（今日卡/红点） |
| 渲染副作用迁移改变结算时机 | 各函数自带按日守卫，迁至 afterAction 后语义「当日首次行动结算」更严格；回归覆盖 |
| mid2 七段连播拉长节奏 | 沿用 supR 静默跳过机制；插章每段 ≤5 场，Esc/点击可快速翻页 |
| 防重入锁误伤弹窗流 | 锁按元素隔离，弹窗/战斗按钮是独立元素天然不受影响；Z 组专测 |
| 离线修行通涨 | 40% 折算+30 日上限，balance-sim 复核每境天数偏移可忽略（<1 日） |
| CSS 大扫除碰坏现版式 | 只删「无引用/被覆盖」规则（逐条 grep 确认），构建期体检兜底，九套回归截图复核 |

## 明确不做（本轮边界）

- 天骄榜排序键不改（境界制→战力制牵一发动全身，仅补展示）；
- 敌方数值/攻击滚雪球不再动刀（v19 已校准，100% 胜率属放置游戏动力幻想范畴）;
- 随机 NPC 四型文案池扩充、斗兽场迁址——收益低，留待后续版本。
